# 微缩潮玩商业摄影导演

**Miniature Product Photography Director** · `miniature-product-photography`

围绕产品实物照片，引导选择摄影参数，构思三套微缩场景，并在选定方案后生成产品摄影图的 AI 工作流。适用于毛绒玩偶、潮玩、手办及小型实物产品。

## 工作流程

1. 上传产品原始照片，补充产品设定与禁忌。
2. 识别产品并锁定外观特征。
3. 逐项选择视觉语言、叙事情绪、色彩关系、构图、光线和场景丰富度。
4. 获取三套有明确物料、空间层次与灯光设计的微缩场景方案。
5. 选择方案，自动规划摄影参数并生成一张默认 **3:4 竖版、无新增文字**的产品摄影图。
6. 按反馈局部调整，持续以原始产品照片约束外观。

## 快速开始

在支持加载技能文件的工具中，将整个仓库作为技能目录使用，并保留 `references/parameters.md` 的相对路径。

也可以在支持项目资料与图像生成的 ChatGPT 环境中，添加 `SKILL.md`、`parameters.md`，并使用 `ChatGPT项目指令.txt` 中的项目指令。原文中的 `references/parameters.md` 指本仓库参数文件；若上传后仅显示文件名，则对应 `parameters.md`。

上传产品原始照片后发送：

> 开始。这张照片是唯一产品外观锚点，请保持产品颜色、表情和结构，不增加四肢或配件。逐项给出摄影参数和推荐，再提供三套微缩场景方案。

想快速完成参数选择，可以回复 **全部推荐**；选择场景时回复 **1 / 2 / 3**，也可回复 **2+3融合**。

## 常用指令

| 指令 | 效果 |
| --- | --- |
| 推荐 | 接受当前参数的推荐选项 |
| 全部推荐 | 自动填写剩余参数并展示三套方案 |
| 自定义：…… | 自定义当前参数 |
| 重做三案 | 保留参数，重新构思场景 |
| 只要提示词 | 选择场景后仅输出最终提示词 |
| 改成…… | 修改指定部分并重新生成 |

## 使用边界

- 需要用户提供产品原始照片；未知结构不应凭空补全。
- 实际生成图片需要运行环境提供图像生成能力；没有该能力时，工作流会交付可复制的提示词。
- AI 图像可能偏离细小刺绣、皮标等细节，成图需对照原照片审阅。
- 不同平台的功能、入口与账号权限可能不同，请以当前运行环境为准。
